    CaptureSourceFiles

    • CaptureSourceFiles(capArray: string[]): void

      List the BFD sections of the exec and core files.

      Usage: maintenance info sections [-all-objects] [FILTERS]

      FILTERS is a list of words, each word is either: + A section name - any section with this name will be printed, or + A section flag - any section with this flag will be printed. The known flags are: ALLOC LOAD RELOC READONLY CODE DATA ROM CONSTRUCTOR HAS_CONTENTS NEVER_LOAD COFF_SHARED_LIBRARY IS_COMMON

      Sections matching any of the FILTERS will be listed (no FILTERS implies all sections should be printed).

      Options: -all-objects Display information from all loaded object files.
